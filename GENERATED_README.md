# personal finance tracker app

## Overview
An app to track personal finances by adding income and expenses, categorizing expenses, providing monthly spending summaries, and exporting data to CSV. It aims to help users manage their finances efficiently with an intuitive interface.

## Goal
Focus on clean UI and offline mode.

## Features
- Add income and expenses  
- Categorize expenses  
- Monthly spending summary  
- Export data to CSV  

## Tech Stack
- React  
- Django  
- PostgreSQL  
- Docker

## Getting Started
1. Clone the repository to your local machine.  
2. Install dependencies for both frontend and backend (React and Django).  
3. Set up the PostgreSQL database.  
4. Use Docker to containerize and run the application.  
5. Start the backend server and frontend development server.
