# Notes Sharing Platform

## Overview
A notes sharing platform for college students designed to facilitate easy sharing and access to academic notes. The platform aims to create a collaborative environment for students to support each other's learning.

## Goal
To enable college students to share and access notes efficiently.

## Features
- Upload notes as PDF
- Search notes by tags or subject
- Bookmark notes
- Upvote and downvote notes

## Tech Stack
- React
- FastAPI
- PostgreSQL

## Getting Started
1. Clone the repository to your local machine.
2. Install the necessary dependencies for both frontend (React) and backend (FastAPI).
3. Set up the PostgreSQL database and configure connection settings.
4. Run the backend server using FastAPI.
5. Start the React development server to launch the frontend.
6. Access the application via the local development URL provided.
